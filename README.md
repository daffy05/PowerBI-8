# Student Performance Analytics Dashboard

## 📌 Project Overview
The **Student Performance Analytics Dashboard** is a Power BI project that analyzes student academic performance using mathematics, reading, and writing scores.

The dashboard helps identify performance patterns based on student demographics, parental education, and test preparation courses.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## 📂 Dataset
**Dataset:** Students Performance in Exams

The dataset includes:
- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## 📊 Dashboard Features

### 1. Student Performance Dashboard
- Average Math Score
- Average Reading Score
- Average Writing Score
- Student Count
- Subject-wise score comparison by parental education level
- Average scores by test preparation course
- Student performance distribution by test preparation course
- Interactive slicers for gender, race/ethnicity, parental education, lunch, and test preparation course

### 2. Student Details Page
- Student-level academic information
- Math, reading, and writing scores
- Total Marks and Percentage
- Performance Category
- Drill-through functionality
- Back navigation button to return to the main dashboard

## 🎯 Key Learning Outcomes
- Data cleaning and transformation using Power Query
- Creating calculated columns and DAX measures
- Designing interactive Power BI dashboards
- Using slicers and filters
- Implementing drill-through functionality
- Creating a two-page analytical report
